02 / Under the hood

Written to be read, checked before it ships.

  1. 01Standards first.Escaped output, nonces and capability checks on every form, and the WordPress coding standards run on all the code.
  2. 02Usable by everyone.Keyboard navigation, visible focus, readable contrast and reduced-motion support are part of the design.
  3. 03Private by default.Built to load no files from other servers. What a visitor sends stays on the site owner's own website.
  4. 04Help that is easy to find.A written guide with search, and questions answered in the comments of the theme's page on ThemeForest.

03 / What I build

What I build

  • Themes

    Classic PHP themes that work on their own, with the Customizer, a child theme, translation files and a right-to-left stylesheet.

  • Elementor widgets

    Widgets for the free Elementor, each with content and style controls, so no Pro licence is needed.

  • Block patterns

    Patterns and block styles made from core blocks, for people who write pages without a page builder.

  • Plugins

    Companion plugins for what belongs outside a theme: content types, forms and demo import.

  • Documentation

    A guide that explains the setup step by step, in plain words, with search.
